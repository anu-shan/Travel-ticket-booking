# TravelGo – Online Travel Ticket Booking System

## Project Overview Overview

TravelGo is a web-based travel ticket booking system that allows users to search for journeys, view travel options, book tickets, and manage their travel details.

## Objectives

- Build a user-friendly travel ticket booking website.
- Develop a minimum of four web pages.
- Implement navigation between all pages.
- Use HTML, CSS, and JavaScript.
- Practice Git and GitHub collaboration.
- Follow a proper Git branching strategy.
- Deploy the website using GitHub Pages.

## Website Pages

1. Home & Search
2. Booking
3. My Ticket
4. Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Team Structure

The project is developed collaboratively by four team members.

- Member 1 – Home & Search
- Member 2 – Booking
- Member 3 – My Ticket
- Member 4 – Contact
